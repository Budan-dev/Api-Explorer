# API Explorer (Rick and Morty Character Viewer)

A React app for exploring Rick and Morty characters using the [Rick and Morty API](https://rickandmortyapi.com/).  
Features include search, responsive grid display, and detailed character pages.  
Deployed on GitHub Pages: [https://budan-dev.github.io/Api-Explorer](https://budan-dev.github.io/Api-Explorer)

---

## Features

- **Search:** Filter characters by name using the search bar.
- **Responsive Grid:** Characters are displayed in a responsive grid (columns depending on screen size).
- **Details Page:** Click a character to view all details on a separate page.
- **Routing:** Uses React Router for navigation.
- **GitHub Pages Deployment:** Ready for static hosting.

---

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Budan-dev/Api-Explorer.git
   cd Api-Explorer
   ```
2. **Install dependencies:**
   npm install
3. **Start the development server**
   npm run dev

   The app will be available at http://localhost:5173 (or as shown in your terminal).
